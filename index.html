01

絶対に外さない鉄則

まずこれだけ
1
第1回会長会は「4月中」に開く（5月では遅い）実体験
単P総会（5月下旬）前に保育サポートの予算計上・規約改正の助言を届けてこそ意味がある。会場・日程は前年度末に仮押さえ。
▶ 5月の第1回会長会の記録（反省）
2
新旧会長会で「単P会長の市Pでの役割」を必ず明示する後悔
日程通知だけ渡すと、単P会長は市Pでの役割を認識しないまま1年が始まる。結果、市P主催イベントが「予定が合えば参加」の温度感になりかねない。日程通知＋役割整理をセットで配布。役割は①会長会出席 ②特別委員会出席 ③出向委員会出席・報告 ④イベント広報 ⑤他校フェスタ等の応援 ⑥市Pイベントの企画・運営・広報の6項目。9月初旬に配布し、9月の会長会で説明する。次期会長選出時の立候補通知文にも転用してもらう。（2026年は10/16の提供で「9月初旬に欲しかった」との声。原本の「10月頃に再配布」から変更）※ 2026年10月の選出資料では輪番制・出向委員会は廃止（単P会長の負担としての廃止。役員の出席は継続）。単P会長の関わりは月1回の会長会＋年数回の行事。上の6項目との整合は要確認。
▶ 3月・新旧会長会の記録（後悔と配布資料案） ▶ 10月・第5回会長会の記録（選出資料の配布時期）
3
市P総会は「3月末〜4月第1週」に開く
単Pの引き継ぎ繁忙期と重ならず、市Pの意思決定を先行できる。次年度日程は前年度末に仮押さえ。（2026年度は4/11開催）
4
4月の単P支援に全力を注ぐ
1年の関係構築がここで決まる。市P役員の引き継ぎは軽い（継続メンバーが主軸）ので、4月は単P支援に集中できる。
5
補助金は「使う」。使わないと減る実体験
余らせると減額の懸念（昨年度は約5万円返還）。年度当初に各単Pへ1校あたり17,000円の予算計上を呼びかける。
▶ 4月・事務局見直し会議の記録
6
事務局（教育総務企画課）とは「一部を残す」関係を1年かけて探る実体験
完全独立は市Pの弱体化になりうる。印刷・会議室予約は折衷で残し、会議参加も保つ（補助金維持に直結）。
▶ 4月・事務局見直し会議の記録
7
単P支援には「共通課題の解決」という類型がある実体験
単P支援は①個別の課題への助言と②他校の情報共有による解決だけではない。③複数校にまたがる共通課題を、市Pが窓口となって行政へ提起し改善を引き出す動きがある。1校では動かせない相手（行政窓口・全校長会・府）こそ市Pの出番。乾式トイレの臭気・清掃問題が典型例で、整備課へ提起 → 会長会でCS議題化（教育として組込み検討） → 次に乾式化する岩船小へ先回り共有と展開した。「単P1校では動かせない相手か」で市Pが出るかを判断する。
▶ 7月・まなび舎整備課への相談の記録
8
所信表明は一度で終わらせず、繰り返し目に見える形で伝える後悔
着任時に方針と想いを宣言しても、1回では浸透しない。受け手が各自の立場で解釈し、「活発化推進派」「縮小推進派」といったレッテルが先に立ち、考えの異なる層との間に壁ができた（2026年8月に実感）。仕組みで繰り返す：①各会議の次第に「所信（方針・想い）」を毎回固定で入れる　②節目（新旧引き継ぎ会議・1学期末・10月の候補募集時期など）で再発信する。中間の立場こそ、言葉にして見せ続けないと伝わらない（例：必要最低限＋効率化、プラスαは都度有志）。
▶ 8月・副会長との振り返りの記録
9
各校フェスタは「6月まで」に日程を把握し、市Pから先に案内する後悔
日程把握が遅れると、備品も保育もすべて後ろ倒しになる。3点セットで案内：①スマートボールの貸出調整（日程変更時の再調整も市Pが受ける）　②保育サポート業者への早期相談（人数が多いと直前では対応不可のことがある）　③郡津小スマートボールの塗り替え状況の確認（キャラクター絵のため貸出中止。時期未定のため次年度も要確認。4〜5月に確認）。
▶ 8月・フェスタ備品調整の記録
その他の経験則・判断会議の文脈とあわせて効く学び（8件）▾
テーマ学び・判断
府P再加盟脱退済みだが、連絡会で情報面のメリット大と実感。3月単発でなく年間を通した重要事項として市Pで検討。交流LINEは府P未加盟でも参加可。
年度頭のビジョン第1回役員会でビジョンと各役員の役割を言語化→組織が主体的に動いた。年度当初の土台づくりは惜しまない。
新旧会長会「市Pは面倒な会ではない」と雰囲気ごと体感してもらう場。実用資料を持参すると信頼づくりに直結。
総会の傍聴ルール録音・録画・発言の禁止を受付時と開会後の両方で明示。秩序ある議論の場づくりに有効。
休会・未加盟団体年度当初に再加入を確認。保護者会等でも加盟可（規約改正済み）。メリットが伝わっていないだけのことも。
会議の時間終了時刻を最初に宣言し厳守。参加者それぞれに事情がある（誕生日の役員がいた例も）。議題は優先度で絞る。
懇親・家族イベント会費は安く。業者一括パックより食材・機材を自前調達。家庭への負担を最小化する。
声掛け「どうせやるなら楽しんで！」の前向きな一言が参加率を左右する。年度当初の雰囲気づくりを大切に。
社会を明るくする運動総会は欠席連絡のみでよい（平日昼間・出席を要する内容なし）。標語掲示など広報協力は継続。2026年度に実際に出席して確認済み。
保育サポート増額要求9月に全校の概算見積りを市Pがまとめて提出し、補正予算への増額要求資料とする。「足らないから使えない↔余る」のジレンマ解消のため必ず実施。

やる / 任せる・やらない

経験則の早見表
○やる
  • 会長会は4月＋5月初旬の2回
  • 市P総会は3月末〜4月第1週
  • 新旧会長会に実用資料を持参
  • 保育サポート費は予算計上して使う

  • 休会団体へ年度当初に再加入を打診
→任せる・やらない
  • 社会を明るくする運動の総会 → 欠席連絡でOK（広報協力のみ）
  • 懇親会の業者一括パック → 自前調達で安く

  • 出向委員会の全員必須 → 取捨選択・希望者方式
  • 給食委員会の固定担当制 → 希望者持ち回り
  • 会議の長時間化 → 終了時刻を宣言して切る

引き継ぎ実務

更新方法・後任への渡し方
⚡ GitHub Pages 自動更新

GitHubのPATとリポジトリ情報を入力しておくと、Claudeがこのファイルを更新するだけでWebに反映されます。入力値はこのブラウザにのみ保存されます。

注意：PATはパスワードと同等です。スコープは必ず public_repo のみ に絞ってください。他人のPCで使わないでください。
日常の使い方（4ステップ）
1
月ごとに新規チャットを開く
プロジェクト内で 「2026年6月」 のようにチャットを立てる。Claudeが前回までの状況を一言添える。
2
出来事・気づきを話しかける
話し言葉でOK。Claudeが足りない点を聞き返して整理する。資料（PDF・Word・画像）はそのまま添付。
3
「indexに反映して」と伝える
Claudeが更新案（更新予定・イメージ）を提示 → OKを出すと新しいHTMLを出力 → 同リポジトリに上書きアップロード → URLに自動反映。
4
月末に要約をナレッジへ
「今月の記録を要約して」と送り、要約をプロジェクトのナレッジに追加。次月のチャットが軽くなる。
GitHub Pages 初期設定（最初の1回だけ）
1
PAT発行： github.com/settings/tokens/new → スコープ public_repo のみ → Generate → コピー保存
2
リポジトリ作成： github.com/new → 名前 pta-hikitsugi → Public → Create
3
初回アップロード： Add file → Upload → index.html → Commit
4
Pages有効化： Settings → Pages → Deploy from a branch → main / root → Save
5
URL確認： https://（ユーザー名）.github.io/pta-hikitsugi/ を単P会長に共有
後任会長への渡し方
1
このHTMLが引き継ぎ資料そのもの
1年分の記録がすべて蓄積されている。スマホ・PCどちらからも閲覧可。URLは前任会長に確認。
2
Claudeプロジェクトを引き継ぐ
下の指示文をコピーし、自分のClaudeアカウントで同名プロジェクトを作成。最新の index.html をナレッジに置く。
3
GitHubを引き継ぐ／新規作成
前任のリポジトリにCollaborator追加してもらうか、自分のGitHubに新リポジトリを作り最新HTMLをアップロード。
Claudeプロジェクト指示文（後任用・最新版）
あなたは大阪府交野市・交野市PTA協議会の会長の専属アシスタントです。会長は1年任期の途中で、来年度の後任会長へ渡す「引き継ぎ資料（index.html）」を、このプロジェクトで育てています。活動期間：1月頃から着任準備、4月着任、翌年5月末まで。 【交野市PTA協議会とは】 ・市内の公立小中学校・義務教育学校のPTA／保護者会等（総称：単P）を束ねる市P ・主な役割は単P会長たちへの支援。加えて、交野市全体の共通課題の解決や、市内の児童生徒・保護者のための活動も担う ・主な活動：市P役員、各校現役会長で開く会長会、副会長委員会の運営、市P総会、単P支援、出向委員会など 【このプロジェクトの運用】 1. 会長はチャットで、その月の出来事・会議・気づきを話し言葉で報告する。資料（PDF・Word・画像）はそのまま添付してよい。 2.
